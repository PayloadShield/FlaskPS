# Development Guide

## Project Structure

```
FlaskPS/
├── flask_payloadshield/             # Main package directory
│   ├── __init__.py                  # Package initialization & exports
│   ├── config.py                    # ComPyPS configuration re-export
│   ├── decorators.py                # PayloadShield.encrypt/decrypt/crypt decorators
│   └── crypto.py                    # ComPyPS handler registry re-export
│
├── examples/                        # Example implementations
│   ├── main.py                      # Full-featured example Flask app
│   ├── private.pem, public.pem      # Generated RSA keys (rsa-hybrid)
│   ├── ec_private.pem, ec_public.pem        # Generated EC keys (ecdh-aes-gcm, ecies)
│   └── hpke_private.pem, hpke_public.pem    # Generated X25519 keys (hpke)
│
├── tests/                           # pytest suite
│   ├── test_handlers.py             # Handler encode/decode roundtrip tests
│   ├── test_config.py               # PayloadShieldEnc.init() tests
│   └── test_decorators.py           # Decorator + Flask test-client tests
│
├── setup.py                         # Classic setup configuration (pip installable)
├── publish.sh                       # Build and publish to PyPI
├── pyproject.toml                   # Modern Python project configuration
├── requirements.txt                 # Development & runtime dependencies
├── README.md                        # Full API documentation
├── MANIFEST.in                      # Files to include in distribution
├── .gitignore                       # Git ignore patterns
└── LICENSE                          # Apache-2.0 License
```

## Installation for Development

### 1. Clone the Repository
```bash
git clone <repository-url>
cd FlaskPS
```

### 2. Create Virtual Environment (Recommended)
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python -m venv venv
source venv/bin/activate
```

### 3. Install in Development Mode
```bash
# Install package with all dependencies
pip install -e .

# Or with development dependencies
pip install -e ".[dev]"

# Or install from requirements
pip install -r requirements.txt
```

## Testing the Package

### Option 1: Run Example Application
```bash
cd examples
python main.py
```

The console prints ready-to-paste Postman requests (URL + JSON body) for
every built-in handler on startup.

The server listens at `http://127.0.0.1:5000`. The PEM files generated by the
example are reused on later starts.

### Option 2: Manual Testing with cURL
```bash
# Terminal 1: Start server
cd examples
python main.py

# Terminal 2: Test endpoints (see the Postman examples printed on startup)
curl http://localhost:5000/health
curl http://localhost:5000/base
```

### Option 3: Run the pytest Suite
```bash
pytest
```

## Publishing

Increment the version in `pyproject.toml`, configure `PYPI_TOKEN`, and run
from the project root:

```bash
export PYPI_TOKEN="pypi-..."
bash publish.sh
```

The script builds the source and wheel distributions, runs `twine check`, and
uploads them to <https://pypi.org/project/flask-payloadshield/>.

## Adding a New Built-in Handler

1. Create `compyps/MyHandler.py` implementing
   `EncryptionHandler.encode(data, config)` / `.decode(encoded_data, config)`.
2. Register it in `compyps/crypto.py`'s `_HANDLERS` dict and export it from
   `compyps/__init__.py`.
3. Add a roundtrip test in `ComPyPS/tests/test_handlers.py`.
4. FlaskPS automatically receives the handler through `compyps`.

## Troubleshooting

### Module Import Errors
```bash
# Reinstall in development mode
pip install -e . --force-reinstall
```

### "No module named 'flask'"
```bash
pip install Flask
```

### Version Conflicts
```bash
# Create fresh virtual environment
python -m venv venv_fresh
venv_fresh/Scripts/activate
pip install -r requirements.txt
```
